## 1. ¿Qué haría exactamente VeriLink?

VeriLink sería una extensión para navegadores como Google Chrome que analiza las direcciones web que visita una persona y le advierte cuando detecta señales sospechosas.

1. El usuario entra a un enlace

Por ejemplo, recibe un mensaje que lo invita a iniciar sesión en una página bancaria.

2. VeriLink analiza la dirección

Busca señales como dominios extraños, nombres que imitan marcas o direcciones incluidas en una lista de sitios reportados.

3. Muestra una advertencia

Indica qué señales encontró y recomienda al usuario verificar el sitio antes de introducir datos personales o bancarios.

La idea no sería prometer que VeriLink detecta todas las estafas, sino ayudar a reconocer riesgos antes de que el usuario confíe en una página.

## 3. ¿Cómo se desarrollaría la extensión?

Para que entiendas qué tendrían que programar, la dividiría en estas partes:

Extensión de Chrome

Ventana emergente con campo para pegar un enlace y botón Analizar.

Motor de análisis

JavaScript revisa la URL y aplica reglas para identificar señales de riesgo.

Fuentes de información

Lista de dominios de prueba y, en una versión más avanzada, una fuente externa de reputación.

Resultado para el usuario

Nivel de riesgo, señales encontradas y recomendaciones.

### Tecnologías que podrían utilizar

| Tecnología                      | Para qué serviría                                         |
| ------------------------------- | --------------------------------------------------------- |
| HTML                            | Crear la estructura de la ventana de la extensión.        |
| CSS                             | Diseñar la interfaz azul de VeriLink.                     |
| JavaScript                      | Analizar las URL y mostrar los resultados.                |
| Chrome Extensions Manifest V3   | Definir los permisos y el funcionamiento de la extensión. |
| Una API de reputación, opcional | Consultar información externa sobre sitios peligrosos.    |

Para el primer prototipo no necesitan entrenar una inteligencia artificial ni desarrollar una base de datos compleja. Pueden comenzar con reglas de detección y un conjunto pequeño de enlaces de prueba.

Importante: revisar una URL mediante reglas propias no garantiza detectar una estafa. El HTTPS o el candado tampoco garantizan que una página sea legítima. Para tener una detección más confiable, después podrían integrar una fuente especializada de reputación de URL.

# Extensión de protección contra estafas digitales

Seguridad preventiva durante la navegación web

¿Qué es?

Es una extensión para navegadores web diseñada para ayudar a las personas a reconocer posibles estafas digitales. Su propósito es identificar señales de riesgo en enlaces y páginas web, advertir al usuario y ofrecer información que le permita decidir si es seguro continuar.

Funciones principales

Análisis de enlaces y páginas web

Examina indicadores de riesgo, como direcciones sospechosas, dominios que imitan a empresas conocidas y otros patrones asociados con posibles intentos de fraude.

Alertas preventivas

Muestra una advertencia cuando encuentra señales de riesgo para que el usuario tenga oportunidad de detenerse antes de ingresar información o continuar.

Explicación del posible riesgo

No se limita a mostrar una alerta: explica qué señales resultan sospechosas, para que la persona comprenda por qué debe tener precaución.

Recomendaciones de seguridad

Sugiere acciones concretas, como verificar el dominio oficial, no proporcionar contraseñas y contactar directamente a la empresa por sus canales oficiales.

Reporte de sitios sospechosos

Como función complementaria, permitiría que los usuarios reporten enlaces que consideren fraudulentos para facilitar su revisión y mejorar la detección.

Objetivo principal

Reducir el riesgo de que las personas sean víctimas de estafas digitales mediante una herramienta accesible que combine análisis preventivo, alertas comprensibles y orientación sobre seguridad en internet.

Importante: estas son las funciones propuestas para el proyecto. No deben presentarlas como funciones ya implementadas hasta que las desarrollen y comprueben su funcionamiento. Una extensión tampoco puede garantizar que todas las estafas sean detectadas.
